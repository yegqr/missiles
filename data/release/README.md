# MISSILES — відкритий набір даних про атаки на Київ

Погодинна база тривог, зведень Повітряних Сил і погоди по Києву з 24.02.2022,
зібрана з **первинних джерел власними парсерами**. Це той самий набір, на якому
рахується модель на [airalert.mylovanov.media](https://airalert.mylovanov.media)
— не витяг і не спрощення.

Оновлюється автоматично двічі на добу: о 06:00 (факти за ніч) і о 12:20 за
Києвом (свіжий прогноз). Вручну — `.venv/bin/python ingest/export_release.py`.

Файли навмисно **не стиснуті**: вони ростуть дописуванням у хвіст, і git
зберігає дельту. Gzip щоразу давав би несхожий blob і гігабайти історії ні за що.

---

## Три шари, які не можна плутати

| Шар | Файли | Що це |
|---|---|---|
| **Довідники** | `00_*` | території, джерела, канали, точки погоди |
| **Сире** | `10_*` – `15_*` | те, що сказало джерело, з полем `raw` і текстом-доказом |
| **Канонічне** | `20_*`, `21_*` | джерела злиті, дублікати й перекриття прибрані |
| **Похідне** | `30_*`, `31_*` | навчальна таблиця і всі видані прогнози |

Сире й канонічне лежать окремо навмисно: **перевірити розмітку можна лише
тоді, коли видно, з якого рядка джерела вона вийшла**. У `10_alerts` є
`raw`, у `11_attack_observations` — `evidence_text`, у `12_readiness_signals`
— `evidence`.

Повний паспорт кожного файла — у [`manifest.json`](manifest.json): кількість
рядків, період, sha256, який парсер його породив і що означають колонки.

## Як завантажити назад у базу

```bash
docker compose up -d          # Postgres 16 на 127.0.0.1:5543
./load.sh                     # схема + дані + перевірка покриття
```

`load.sh` вантажить **тільки базові таблиці**. Похідні шари — це представлення:
їх створює `schema.sql`, і база перераховує їх сама. Дві копії однієї правди
неминуче розійшлися б.

`schema.sql` — це реальний DDL із робочої бази, включно з представленнями. Тобто
означення канонічного ряду, доби нальоту й масованої атаки тут не переказані
словами, а **виконуються**.

## Як просто подивитись числа

Просто читати. Усе — CSV з заголовком, UTF-8, кома, час в ISO 8601.

```python
import pandas as pd
d = pd.read_csv("30_daily_features.csv")        # навчальна таблиця
a = pd.read_csv("21_alerts_daily.csv")
a = a[a.region_code == "kyiv_city"]                # ТІЛЬКИ місто
```

## Чотири граблі, на які наступають першими

**Доба нальоту, а не календарна.** `raid_day` — це 12:00 → 12:00 наступного дня,
підписана датою початку. Наліт 22:00 → 05:00 — одна подія; календарна північ
ріже її навпіл і робить дві половинчасті доби.

**Рівні територій вкладені.** Область = обʼєднання районів. Сума по всьому
файлу `21_alerts_daily` рахує ті самі хвилини тричі. Фільтруйте `region_code`.

**`y_attacked IS NULL` — це «невідомо», а не «атаки не було».** До 2024 року
формат супроводу цілей ще не склався. Такі доби в навчання не йдуть, і
приймати NULL за нуль означає навчити модель на сотнях фальшивих тихих діб.

**Треки — це повідомлення, а не борти.** `*_tracks` рахує, скільки разів
зафіксовано ціль курсом на місто. Одне повідомлення може означати групу дронів.
Кількості ракет і дронів **саме по Києву не публікує ніхто** — ні Повітряні
Сили (дають країну без розбивки), ні КМВА (дає наслідки). Колонки «20 ракет на
Київ» у цьому наборі немає і бути не може.
