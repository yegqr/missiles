# Словник даних

## Таблиці

### `regions`
Території моніторингу: м. Київ, Київська область, 7 районів області.
`alerts_in_ua_uid` — ідентифікатор у сторонньому API, лишений для сумісності.

### `alerts`
Тривоги з усіх джерел одночасно. Джерела не перезаписують одне одного —
розрізняються колонкою `source`, пріоритет задано в `alert_sources`.

| Колонка | Опис |
|---|---|
| `started_at`, `finished_at` | UTC; `finished_at IS NULL` = триває |
| `duration_min` | обчислювана |
| `raid_day` | обчислювана, доба нальоту |
| `causes` | тип загрози (`drone`, `missile`) — лише з реєстру КМДА, з 2026 |
| `source` | `kyiv_digital`, `tg_air_alert_ua`, `official`, `volunteer` |

### `tg_messages`
Сирі повідомлення каналів. Зберігаються **всі**, не тільки профільні: правила
розбору змінюються, і перепарсити треба без повторного викачування каналу.

### `attack_observations`
Одне твердження одного джерела про одну добу. Ключ — `(raid_day, source,
metric, scope)`.

`scope` розрізняє те, що не можна складати:
- `kyiv` + `*_tracks` — скільки разів зафіксовано ціль курсом на Київ
  (спостереження, **не** кількість бортів)
- `ua` — точні національні числа зі зведень Повітряних Сил
- `kyiv` + наслідки — влучання, загиблі, поранені

`tier`: `official` формує лейбли; `monitor` дає лише ознаки; `dataset` — звірка.

### `weather_hourly` / `weather_forecast`
Факт і прогноз розведені навмисно: прогноз має власний `issued_at`, без чого
неможливо чесно відтворити, що було відоме на момент відсічки.

`visibility` в історії порожня — ERA5 цієї змінної не містить.

### `readiness_signals`
Зльоти носіїв зброї. `is_standdown = true` — «відбій загрози по МіГ-31К»;
пара зліт+відбій дає тривалість загрози.

### `calendar_days`
Свята українські й російські **в різних колонках** з вагами 1–3: гіпотези
протилежні за напрямком, змішувати не можна. Плюс тривалість темного часу
й ознака опалювального сезону.

### `ingest_runs`, `ingest_expectations`, `parse_state`
Службові: лог заходів, строк придатності кожного потоку, курсор парсера.

## Представлення

| Назва | Призначення |
|---|---|
| `v_alerts_canonical` | один безрозривний ряд тривог на регіон зі злиттям перекриттів |
| `v_canon_hours` / `v_canon_daily` | тривоги по годинах / добах нальоту |
| `v_weather_daily` | добова погода з окремим нічним вікном |
| `v_hourly_features` | погодинна матриця «погода + тривога» |
| `v_label_attacked` | голосування офіційних джерел про факт удару |
| `v_label_counts` | медіана по джерелах і позначка суперечності |
| `v_daily_labels` | лейбли на добу |
| `v_daily_features` | **навчальна таблиця**: `*_prev` — ознаки, `y_*` — цілі |
| `v_readiness_daily` | зльоти носіїв по добах |
| `v_health`, `v_freshness`, `v_coverage` | стан системи |

## Функції

- `raid_day(timestamptz) -> date` — доба нальоту, 12:00→12:00 Київ
- `kyiv_day(timestamptz) -> date` — календарна доба за Києвом
- `kyiv_hour(timestamptz) -> smallint` — година за Києвом
