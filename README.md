# MISSILES — база даних моніторингу атак на Київ

Погодинна база тривог, погоди й сигналів атак по Києву з 24.02.2022, яка
оновлюється сама. Фундамент під модель прогнозування обстрілів.

**Дані одним каталогом**
- [`data/release`](data/release/README.md) — увесь набір у CSV.gz, по шарах,
  з паспортом кожного файла (`manifest.json`), реальним DDL (`schema.sql`) і
  скриптом `load.sh`, який піднімає з нього базу з нуля
- [`docs/SCHEMA.md`](docs/SCHEMA.md) — що означає кожна колонка і де граблі

**Документація**
- [`docs/METHODOLOGY.md`](docs/METHODOLOGY.md) — методологія розмітки: чому
  цільова змінна така, звідки беруться лейбли, як влаштована крос-валідація
- [`docs/HANDOVER.md`](docs/HANDOVER.md) — **для інженера моделі**: що в базі,
  що можна подавати в модель, що виміряно, де граблі

---

## Запуск

```bash
cp .env.example .env
docker compose up -d
./scripts/migrate.sh
python3 -m venv .venv
.venv/bin/pip install "psycopg[binary]" psycopg_pool telethon python-socks
```

Історичне завантаження (одноразово, кілька годин на телеграм-канали):

```bash
.venv/bin/python ingest/kyiv_digital.py                       # тривоги м. Київ, уся історія
.venv/bin/python ingest/tg_telethon.py air_alert_ua backfill  # канал тривог
.venv/bin/python ingest/tg_telethon.py kpszsu backfill        # канал Повітряних Сил
.venv/bin/python ingest/tg_parse.py                           # -> тривоги області й районів
.venv/bin/python ingest/kpszsu_parse.py                       # -> зведення і треки на Київ
.venv/bin/python ingest/readiness_parse.py                    # -> зльоти носіїв
.venv/bin/python ingest/weather.py archive                    # погода ERA5
.venv/bin/python ingest/calendar_build.py                     # свята, тривалість ночі
```

Postgres 16 у контейнері `missiles-pg`, `127.0.0.1:5543`.

## Оновлення

| Скрипт | Частота | Що робить |
|---|---|---|
| `scripts/alerts.sh` | 5 хв | тривоги по місту (реєстр КМДА) |
| `scripts/telegram.sh` | 15 хв | добір повідомлень каналів + перерозбір |
| `scripts/weather.sh` | година | оперативна погода + прогноз |
| `scripts/daily.sh` | доба 06:40 | реаналіз ERA5 + продовження календаря |
| `scripts/health.sh` | доба 09:00 | звіт про стан конвеєра |
| `scripts/crosscheck.sh` | вручну | звірка з зовнішнім датасетом |
| `ingest/export_release.py` | вручну | перезбирає `data/release` з бази |

Усе в cron. Кожен скрипт бере `flock`, кроки ізольовані. Парсери мовчки
пропускаються, якщо канали не виросли.

**Чому 5 хвилин достатньо, а вебхук не потрібен.** Джерела тривог віддають не
«стан зараз», а повну історію з точними часами початку й відбою. Пропущений
або впалий запуск нічого не втрачає: наступний добере навіть тривогу, що
встигла початись і скінчитись між проходами.

## Дані

| Що | Джерело | Період |
|---|---|---|
| Тривоги м. Київ | реєстр КМДА (`kyiv.digital`) | 25.02.2022 → |
| Тривоги область і 7 районів | власний парсер `@air_alert_ua` | 15.03.2022 → |
| Зведення ПС, треки цілей на Київ | власний парсер `@kpszsu` | 2019 → |
| Зльоти носіїв (МіГ-31К, Ту-95/160, «Калібр») | той самий канал | 2023 → |
| Погода погодинна, 20 показників | Open-Meteo ERA5 | 24.02.2022 → |
| Прогноз погоди | Open-Meteo forecast | на 7 діб |
| Календар: свята, тривалість ночі | розрахунок | 2022–2027 |

Принцип: **первинне джерело і власний парсер**. Готові датасети — лише
незалежна звірка (`scripts/crosscheck.sh`), не основа.

Наш парсер каналу тривог звірено з датасетом Vadimkin: розбіжність 0,07%
(9 162 проти 9 156 тривог, три знайдені додатково, жодної втраченої).

## Дві часові умовності

Час зберігається в UTC. Доба рахується двома способами:

- `kyiv_day()` — календарна доба за київським часом
- `raid_day()` — **доба нальоту**: з 12:00 до 12:00. Наліт 22:00 → 05:00 це
  одна подія, і календарна доба ріже її навпіл. Уся добова аналітика йде
  по `raid_day`

Нічне вікно скрізь — 22:00–06:00 за Києвом.
